## M0 — Scaffold

- **`ORCHESTRATOR_MODEL` default changed from `claude-sonnet-4-6` to `claude-sonnet-5`.** `claude.md` §2 explicitly says to re-verify the current model name rather than trust what's hardcoded in the doc. `claude-sonnet-5` is the current-generation Sonnet as of this scaffold (Aug 2026) — cheaper-tier intro pricing runs through 2026-08-31. Re-verify again at M4 build time against console.anthropic.com before wiring the actual API call.
- **DB driver**: `psycopg[binary]` (psycopg v3), matching the `postgresql+psycopg://` scheme already specified in `claude.md` §4's `DATABASE_URL`.
- **Ruff/mypy config lives in `apps/api/pyproject.toml`**, not the repo root — CI and local dev both run lint/type-check commands with `apps/api` as the working directory, and mypy does not reliably walk up parent directories to find config. Keeping config colocated avoids ambiguity.
- **Alembic migration 001 hand-written**, not autogenerated — no local Postgres was available to run `alembic revision --autogenerate` against during scaffolding (this machine has no Docker/Python installed yet). Schema matches `claude.md` §5 exactly. Re-verify the migration applies cleanly once Docker is running locally (this is M0's actual acceptance test).
